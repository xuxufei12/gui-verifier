# 开源发布准备

本地历史文件保持原位。公开版本通过 `python tools/build_public_release.py` 从明确白名单构建到 `outputs/public-release/`，并输出 `outputs/gui-verifier-public.zip` 与逐文件SHA-256清单。**应发布该目录，不要对原工作目录直接 git add .**

公开：src、请求样例、四个不依赖内部平台的测试文件、训练/评估/分析和自制界面生成脚本、README、结果/训练/第三方说明、MIT、依赖文件、汇总报告。XIAOHONGSHU.md 是独立宣传草稿，不收入源码发布包。

不公开：SSH/上传/供应商自动化脚本、运维配置、原始数据、教师输入输出、模型权重、适配器、原始日志、内部结果归档及历史实验文档。历史README备份仍在本地 docs/README_PRE_EXPERIMENT004.md。

代码基于既有MIT许可整理。GitHub目标为 `xuxufei12/gui-verifier`，通过经过检查的公开目录提交。公开仓库只包含本清单范围，不包含历史工作目录。小红书文案单独保留，发布GitHub不等于发布社交帖子。

## 发布前剩余事项

- 填入真实GitHub地址；若要发布权重和真实数据，另做许可、个人信息和教师服务条款审查。
- README已明确没有独立人工测试、没有多seed，保留这些限制。
- 精确复现数字需要当前未公开的固定数据和适配器；不能把源码可运行写成公开数据可完全复现。
- 当前静态扫描只覆盖常见敏感模式，不是形式化秘密检测保证。审阅白名单包后发布。
